## Troubleshooting Guides

### 1. Microsoft Outlook — Emails Not Appearing in Sent Items

**Problem:** Recently sent emails do not appear in the Sent Items folder.

**Possible Causes:**

* Synchronization delays
* Incorrect Outlook view or filters
* Cached mailbox data issues
* Incorrect account configuration

**Troubleshooting Steps:**

1. Verify the Sent Items folder and remove any unintended filters.
2. Check Outlook synchronization status.
3. Confirm the correct mailbox and account are selected.
4. Restart Outlook and check whether the issue persists.
5. If necessary, investigate the Outlook profile and mailbox synchronization.

**Expected Result:** Newly sent emails appear correctly in Sent Items after the underlying issue is resolved.

### 2. Microsoft Office — Activation and Sign-In Issues

**Problem:** Office applications display activation errors or cannot connect to a work account.

**Troubleshooting Steps:**

1. Confirm the user is signing in with the correct work account.
2. Verify the assigned Microsoft 365 license with the authorized administrator.
3. Check internet connectivity and service status.
4. Review the displayed error code and relevant sign-in information.
5. Escalate unresolved licensing or access policy issues to the appropriate administrator.

**Expected Result:** The user can access licensed Office features after the account or activation issue is resolved.

### 3. Windows — Basic Network Troubleshooting

**Problem:** A computer cannot access internal resources or the internet.

**Troubleshooting Steps:**

1. Check the network cable or Wi-Fi connection.
2. Verify the IP address and network adapter status.
3. Test connectivity using `ping` where permitted.
4. Check DNS resolution and VPN connectivity if applicable.
5. Escalate persistent network or infrastructure issues to the network team.

**Expected Result:** Network connectivity is restored or the underlying issue is documented for escalation.

## Troubleshooting Methodology

1. Identify and clarify the reported issue.
2. Gather relevant symptoms and error messages.
3. Investigate likely causes.
4. Apply appropriate troubleshooting steps.
5. Verify the outcome with the user.
6. Document the resolution and preventive recommendations.
